# Item icons

Every item already shows a drawn icon (distinct knife and gun shapes, coloured by rarity). To use a real image instead, drop a PNG here named after the item id. The site picks it up automatically, no code changes needed.

Order used by the site: /icons/<id>.png, then the MM2 wiki image by item name, then the drawn icon.

Recommended: square PNG, transparent background, at least 128x128px.
